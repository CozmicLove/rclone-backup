Privacy Policy

Personal Rclone Backup is intended for personal automated file backup to Google Drive.

Data Access and Usage

Google Drive data is accessed only for authorized file backup, storage, and restoration purposes.

Data Sharing

The application does not sell or share personal data with third parties.

Data Storage

Backup files are stored in the user's own Google Drive account.

User Control

The user can revoke application access at any time through their Google Account settings.
